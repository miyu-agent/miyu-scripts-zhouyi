# 周易卜卦

Miyu 脚本包，带一件工具 `zhouyi`：三枚硬币掷六次起卦，交回本卦和变卦。只起卦，解读归 AI。

**起卦法**：每次掷三枚硬币，正面记 3、反面记 2，三枚相加得 6、7、8、9：

| 数 | 名 | 爻 | 动不动 |
|---|---|---|---|
| 6 | 老阴 | 阴 | 动，变阳 |
| 7 | 少阳 | 阳 | 不动 |
| 8 | 少阴 | 阴 | 不动 |
| 9 | 老阳 | 阳 | 动，变阴 |

自下而上掷六次（初爻到上爻）得本卦；6、9 阴极生阳、阳极生阴，变过之后是变卦。没有动爻时变卦同本卦，照样交回两卦。卦序照文王卦序。

| 参数 | 说明 |
|---|---|
| `question` | 问的事，原样带回，不参与起卦 |

输出：每一爻的硬币正反、数、老少阴阳（卦象自上而下画），本卦、动爻（如「初九（老阳变阴）」）、变卦，卦名带卦序和上下卦。

`Clicall: no`：只能直接调，不能经 `miyu call` 反复起卦。随机数取自系统熵源，没有种子参数。
