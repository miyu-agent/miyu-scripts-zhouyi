# I Ching divination

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `zhouyi`, which casts an I Ching hexagram by tossing three coins six times and returns the primary hexagram and the changed hexagram. The tool only casts the hexagram; interpreting it is left to the AI.

**How a hexagram is cast**: each toss uses three coins, where heads count 3 and tails count 2, so the three coins add up to 6, 7, 8 or 9:

| Number | Name | Line | Moving? |
|---|---|---|---|
| 6 | Old yin | Yin | Moving; changes to yang |
| 7 | Young yang | Yang | Not moving |
| 8 | Young yin | Yin | Not moving |
| 9 | Old yang | Yang | Moving; changes to yin |

The six tosses build the primary hexagram from the bottom up (from the first line to the top line). A 6 or a 9 is yin or yang at its extreme turning into its opposite, and once these lines have changed, the result is the changed hexagram. When there are no moving lines, the changed hexagram is the same as the primary hexagram, and the tool still returns both. Hexagrams are numbered in the King Wen sequence.

The tool takes this parameter:

| Parameter | Description |
|---|---|
| `question` | The matter you are asking about. The tool echoes it back unchanged in the output; it plays no part in casting the hexagram. |

The output contains: the heads and tails of the coins for each line, its number, and whether it is old or young yin or yang (the hexagram is drawn from the top down); the primary hexagram; the moving lines (for example `初九（老阳变阴）`); and the changed hexagram. Each hexagram name comes with its number in the sequence and its upper and lower trigrams.

`Clicall: no`: the tool can only be called directly; it cannot be called through `miyu call` to cast hexagrams over and over. The random numbers come from the system's entropy source, and there is no seed parameter.
